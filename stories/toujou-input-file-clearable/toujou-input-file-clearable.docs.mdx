# Toujou Input File Clearable

A wrapper component that adds a clear button to a file input. It allows for resetting the file input.

## Slots

| Slot | Description |
|---|---|
| `input` | The file input element. Must be an `<input>` element |
| `clear-button` | Button shown when a file is selected. Clicking it clears the file input |

## Behavior

- On load, only the file input is visible
- Selecting a file shows the `clear-button` slot
- Clicking the button sets the file input's `files` property to an empty `FileList` and hides the `clear-button` slot
- Click events on the button are prevented from bubbling to avoid unintended form submissions

## Accessibility

- Use `aria-label` on the button to provide a meaningful description for screen readers
- The `type="button"` attribute on the button is important to prevent accidental form submission
